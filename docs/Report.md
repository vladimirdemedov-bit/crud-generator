# Отчёт о разработке плагина

VS Code довольно гибкая IDE в плане работы с плагинами. У неё объемный набор функций для разработки сторонних функциональных возможностей. Также есть изолированная среду выполнения этих самих возможностей, что позволяет безопасно добавлять новые команды, инструменты и интеграции без риска для основной программы.

## Жизненный цикл плагина
1. Активация - при первом вызове команды VS Code загружает расширение через `activate`
2. Регистрация - плагин регистрирует команды через `vscode.commands.registerCommand()`
3. Подписка - все зарегистрированные компоненты добавляются в `context.subscriptions` для автоматической очистки
4. Деактивация - при выгрузке расширения через `deactivate()`

## Как мой плагин взаимодействует с VS Code 

## Пользовательский интерфейс

- `vscode.window.activeTextEditor` 
Через функцию `window` плагин получает доступ к текущему текстовому редактору и в дальнейшем работает в нем
- `vscode.window.showInputBox()` 
Получает доступ к окну ввода чтобы принять строку от пользователя в getInput, activate
- `vscode.window.showErrorMessage()`
Выводит информацию об ошибках в getInput, activate

## Работа с редактором

- `editor.selection`
Получает текущее выделение текста или позицию курсора в getInput, activate
- `editor.document`
Получает объект документа для дальнейшего чтения в addMissingIncludes
- `editor.edit()`
Открывает документ для внесения изменений в addMissingIncludes, activate

## Работа с документом

- `document.lineCount`
Получает количество строк в документе в addMissingIncludes
- `document.lineAt(i)`
Получает текст конкретной строки по индексу в addMissingIncludes
- `editor.document.getText()`
Извлекает выделенный текст в getInput

## Редактирование

- `vscode.Position()`
Вычисляет позицию для вставки текста в addMissingIncludes
- `editBuilder.insert()`
Вставляет текст в указанную позицию в addMissingIncludes
- `editBuilder.replace()`
Заменяет выделенный текст на сгенерированный код в activate

## Команды
- `vscode.commands.registerCommand()`
Регистрирует новую команду в палитре команд в activate
