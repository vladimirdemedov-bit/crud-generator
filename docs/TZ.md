# Техническое задание: CRUD Generator

## Общие сведения и цель

`Название плагина:` CRUD Generator
`IDE:` VS Code
`Основная цель:` Автоматизировать создание сущностей с CRUD репозиториями и методами, часто используемыми разработчками при написании кода на с++  
`Целевая аудитория:` Разработчики, работающие в области ООП

## Текущее состояние и контекст

`Проблема:` При создании сущности разработчик вручную пишет класс с полями, getter/setter методы и CRUD репозиторий. На одну сущность может уходить до 10 минут шаблонных действий, что снижиает эффективность разработки
`Аналоги:`
  - `Встроенные vs code шаблоны` - не адаптируются под запросы пользователя
  - `Генератор классов с++` - не генерируют репозитории и методы, удобные для работы с полями

## Общая идея работы
Пользователь вводит строку с описанием сущности: имя сущности, необходимые поля, и , если нужно, указывает тип сущности, а плагин автоматически генерирует:
- Код сущности class/struct с полями и, в случае класса, getter/setter методами
- Код для CRUD репозитория с методами "создать, прочитать, обновить, удалить"
- Доп. фишка: добавляет недостающие библиотеки (#include) в файл

## Функциональные требования

- Команда в палитре команд VS Code
- При отсутствии выделенного текста - всплывающее окно ввода
- Вывод ошибок в случае неверного текста строки

## Логика работы
1. Пользователь открывает cpp файл
2. Вызывает команду через палитру команд
3. Выделяет текст с описанием сущности или вводит его сам 
4. Плагин парсит строку, генерирует код сущности и CRUD репозитория
5. Сгенерированный код вставляется вместо введенной строки, при необходимости добавляются библиотеки
